# PeriNode24

PeriNode 24 ist ein Zündmodul mit 24 Kanälen und stellt die Standardeinheit dar, welche mehr als einen Zünder pro Kanal auslösen kann.
Ausgelegt ist das Modul für 8 gleichzeitige Zünden mit jeweils 4 in Reihe geschalteten Brückenzündern Typ A.
Wenn nicht alle Kanäle gleichzeitig zünden, kann 6 in Reihe geschaltete Brückenzünder ausgelöst werden, bei guten Bedingungen ggfs. auch mehr.
