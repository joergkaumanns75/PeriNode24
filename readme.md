# PeriNode4

PeriNode 4 ist ein Zündmodul mit 4 Kanälen und stellt die kleinste Einheit dar, welche mehr als einen Zünder pro Kanal auslösen kann.
Ausgelegt ist das Modul für 4 gleichzeitige Zünden mit jeweils 4 in Reihe geschalteten Brückenzündern.
Wenn nicht alle Kanäle gleichzeitig zünden, kann 6 in Reihe geschaltete Brückenzünder ausgelöst werden, bei guten Bedingungen ggfs. auch mehr.
